## 文件说明

- `watchlist.md`：每日汇总用的名单（只含「纳入每日汇总」的账号），按消息质量等级分组的表格。**给 Grok 读这个。**
- `accounts.json`：全部账号的完整结构化数据（含不纳入汇总的账号）。
- `accounts.csv`：同上，CSV 格式，可用 Excel 打开。

## 字段
